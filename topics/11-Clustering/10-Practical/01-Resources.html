Clustering: k-means, Gaussian Mixtures, DBSCAN, AGNES, K-modes and K-prototypes

As with previous weeks, the working environment for this week's practicals is a set of Jupyter notebooks.

Each of these notebooks should be run using jupyter-lab or VS-code.

  • Notebook 1 (01-KM_GMM.ipynb) applies K-means and GMM to blob data.
  • Notebook 2 (02-GMM_DBSCAN.ipynb) applies GMM nd density-based clustering (DBSCAN) to more generated data.
  • Notebook 3 (03-GMM_KM-DigitsData.ipynb) applies these techniques to find 10 clusters within the digits data
  • Notebook 4 (04-KM.ipynb) provides a very detailed run of K-means to generated data, showing how clustering metrics can be used
  • Notebook 5 (05-AGNES.ipynb) compares linkage functions on a simple dataset, using the AGNES hierarchical clustering algorithm
  • Notebook 6 (06-Kmodes-StudentGrades.ipynb) applies K-modes clustering to a small set of notional student grades
  • Notebook 7 (07-KmodesPrototypes-AutoMPG.ipynb) applies k-modes and k-prototypes clustering on MPG data used in R's ggplot2 demos

Each notebook is extensively annotated. Students are advised to run each notebook one-by-one, and to consider how they can contribute to their CA2 attempts.
