Other resources

W3 Schools Numpy Tutorial

W3 schools provides a tutorial in bite-sized pieces, with each lesson offering simple examples that can run in your browser.

The tutorial has 3 categories:

  • Basic: how Numpy works in practice - all of the lessons in this category are relevant to this module
  • Random: data distributions (normal, uniform and, to a lesser extent, exponential, Poisson and Chi-square distributions are relevant to this module).
  • ufuncs (Universal functions) extend conventional Python functions to work seamlessly with Numpy ndarray variables. They also permit developers to work on "normal" Python variables as if they were Numpy variables, and thus to benefit from vectorisation. If the expression is wrapped in a ufunc, developers can avoid writing loops, or even list comprehensions to iterate over vectors and arrays, because the expression is vectorised implicitly and applied to matching elements of its arguments. Apart from simplifying the code, vectorisation is much more efficient, because the expression is converted to fast operations that occur below the Python layer, directly in its C-language runtime. I recommend looking at the first 5 lessons and the last lesson Set Operations in this lesson category, as these lessons may prove useful to you in this module.

Lastly, there is a W3 Schoopls quiz you can attempt to test your knowledge.

Numpy official documentation

Numpy is a mature project and has comprehensive and well-written online documentation.

After attempting the W3 Schools lessons above, you might also find it helpful to go a bit deeper into those Numpy concepts.

The Absolute Beginner's Guide is pitched at a similar level to the W3 Schools lessons, but provides more background, contezt and examples.

If you have time, the User Guide will improve your abilities, by taking you from competent to confidently using Numpy.

The Reference Guide is not a learning resource as such, but will be more useful to you when trying to find and configure Numpy features while working on your programming assignments.

Lastly, the Numpy site also has its own online tutorial sourced from the community, but it is more advanced than is necessary for this module.

Other resources

Youtube videos are available, but the scope for interacting with the content is limited and so, for active learners in particular, maintaining focus and retaining the content might be difficult. They are best consumed as background information. Also, be careful: older videos will describe versions of Numpy prior to version 2.0. Significant changes were made when Numpy 2.0 was introduced, some of which broke existing code that used Numpy.
