Overview

The second topic in this week's lecture is also being presented in notebook format, instead of slides, because it is easier to show how pandas works by using it in practice.

Pandas plays a huge role in the python data science ecosystem. Typically, it provides the data structures that are used to store and manipulate the data used for machine learning.

Much of the attention later in the module is on machine learning algorithms and their interpretation and validation. However, the machine learning pipeline and model building steps are heavily dependent on pandas.

Other resources

There are even more learning resources for Pandas than there are for Numpy, because many AI engineers use Pandas but rarely need to access the Numpy layer underneath.

W3 Schools

W3 Schools offers an introductory tutorial on Pandas use.

Three categories of lesson are provided:

  • Basic - introductory material on the main Pandas data structures (Series and Dataframes), how to manipulate and populate them with data, etc.
  • Cleaning data - a very important operation during Exploratory Data Analysis
  • Advanced - the Pandas library offers correlation and plotting, without using other libraries. That said, specialised libraries offer more configuration options and richer output choices.

We will consider Cleaning data as part of Exploratory Data Analysis.

I recommend reviewing all the material in this tutorial. However, it should be seen mainly as a starting point, because it omits many useful Pandas capabilities.

Pandas community site

The introductory tutorials are excellent, and are organised by common tasks.

They are more comprehensive than the W3 Schools equivalent. The structure is very attractive, with a series of common questions followed by examples in code, with discussion and explanation.

For example, there is a lesson on How do I select a subset of a Dataframe ?.

This is broken into separate questions, with practical example code for you to use.

In this module, we do not address time series data, so that lesson int relevant, but arguably the others are.
