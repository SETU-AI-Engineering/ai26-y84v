Python tools

This page is intended to be a minimal overview of the Anaconda distribution and jupyter-lab interface. For more detailed guides have a look at Anaconda's official documentation.

Signup for AI Coding Help

Recently added to the Anaconda Navigator is the ability to use AI to help with coding when using Jupyter-lab - this is our preferred IDE for this module.

The use of AI in coding and in data mining is fundmentially changing the way we work, and it can both help and hinder our learning. We will talk more about this in the lectures, but we recommend that you do not use this AI coding feature within the jupyter-lab environment. Our goal here is to help you learn the material, and not just to produce the listed deliverables.

Anaconda Navigator

The Anaconda distribution supports a large number of python tools and to simplify their use, the distribution includes a small application called the Anaconda Navigator. For our purposes, there are two important items:

  • The Environments tab, on the left, that opens graphical interface to the conda package manager.
  • The jupyter-lab card near the top right, that starts the jupyter-lab kernel back-end and opens the front-end in a browser window.

Using Anaconda prompt instead

Please note that the web server for jupyter-lab can also be started from the command line, using

1
jupyter-lab

When the server component is ready, it will automatically launch the client component in a tab in the user's default browser.

Using Visual Studio Code

If students have already installed VS Code, they might choose to use this application to develop Jupyter notebooks. Many of the features of jupyter-lab have been ported to VS Code extensions, so that is also a good option.

There is a detailed official guide which we do not replicate here.

As an alternative to following the official guide, students have reported success by attempting to edit an existing Jupyter notebook file, and then answering the prompts to install and configure extensions recommended by VS Code itself.
