Overview

The notebook for this week (01-hrAnalytics.ipynb) is concerned with seaborn-based visualisations, and on how you can quickly get a sense of what is happening even in a moderately complex data set (archive.zip).

Note that this notebook uses widgets to select visualisations dynamically. This is useful for development and exploration, but should be supplemented with a set of visualisations chosen by the developer as being significant. These significant visualisations should be discussed and interpreted for the benefit of notebook consumers.

The exercise is to extend the notebook, and also to consider how to develop a set of visualisations suitable for your CA1 attempt, which should be structured so that it is repeatable (using good programming practices, efficient use of libraries, etc.).
